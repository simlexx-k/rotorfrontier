# Security policy

RotorFrontier is a production-alpha browser game. Security fixes are accepted for the
latest `main` branch.

Please do not publish a working exploit in a public issue. Instead, use GitHub's
private vulnerability reporting feature for this repository and include:

- affected browser and version;
- reproduction steps and impact;
- whether the issue requires a co-op peer or crafted invite;
- a minimal proof of concept, if safe to share;
- any recommended mitigation.

Never include real credentials or personal connection codes. Co-op invite and answer
codes can contain ICE candidates and should be treated as short-lived private data.

Expected response targets are best-effort during alpha: acknowledgement within seven
days and a remediation plan within thirty days for confirmed issues.
